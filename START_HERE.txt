🔗 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

POST   http://localhost:5000/api/auth/signup
       Register new user (name, email, password)

POST   http://localhost:5000/api/auth/login
       Login user (email, password) → returns JWT token

POST   http://localhost:5000/api/tests/save
       Save test result (requires Bearer token)

GET    http://localhost:5000/api/tests/history
       Get all user tests (requires Bearer token)

GET    http://localhost:5000/api/tests/stats
       Get user statistics (requires Bearer token)

📊 DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════

users TABLE:
├─ id (Primary Key, Auto-increment)
├─ name (VARCHAR 100)
├─ email (VARCHAR 100, UNIQUE)
├─ password (VARCHAR 255, bcrypt hashed)
└─ timestamps (created_at, updated_at)

test_results TABLE:
├─ id (Primary Key, Auto-increment)
├─ user_id (Foreign Key → users.id)
├─ wpm (DECIMAL 5,2)
├─ accuracy (DECIMAL 5,2)
├─ mistakes (INT)
├─ typed_text (LONGTEXT)
├─ duration (INT - seconds)
└─ test_date (TIMESTAMP, indexed)
